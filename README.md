# Баллы Добра

## О проекте

Баллы Добра — это социально значимый веб-сервис для мотивации детей к учебной, творческой, спортивной и общественной деятельности. Дети загружают дипломы и сертификаты, получают за них баллы, а затем обменивают баллы на реальные награды: путёвки в лагеря, экскурсии, мастер-классы, квесты.

## Ключевая идея

Преврати свои достижения в возможности. Каждый диплом или грамота приносит баллы. Чем выше уровень мероприятия, тем больше баллов. Накопленные баллы можно обменять на путёвки в лагеря у моря, экскурсии в Кремль и Петергоф, мастер-классы по робототехнике и 3D-рисованию, квесты.

## Функционал

- Регистрация и вход для детей и администратора
- Добавление достижений с загрузкой фото диплома
- Автоматический расчёт баллов (уровень школы, города, региона, страны, мира)
- Модерация достижений администратором
- Каталог наград с фильтрацией по типу и городу
- Обмен баллов на мероприятия
- Личный кабинет с историей баллов и бронированиями
- Челленджи с загрузкой фото подтверждения
- Рейтинг детей (доска почёта)
- Загрузка аватара пользователя
- Просмотр подробной информации о каждом мероприятии

## Роли пользователей

Ребёнок может добавлять достижения, просматривать каталог, обменивать баллы.

Администратор может проверять достижения, одобрять или отклонять их, добавлять новые мероприятия и челленджи.

## Технологии

Проект написан на Node.js с использованием Express. База данных — SQLite. Фронтенд — HTML, CSS, JavaScript.

## Как запустить

Установите Node.js с официального сайта. Откройте терминал в папке проекта. Выполните команду npm install для установки зависимостей. Затем выполните node server.js для запуска сервера. Откройте браузер и перейдите по адресу http://localhost:3000.

## Структура проекта

Папка images содержит все картинки для мероприятий, аватара по умолчанию, иконки глазков для пароля, фавикон и иконки для манифеста. Папка uploads создаётся автоматически для загруженных дипломов и аватаров. Файл database.sqlite создаётся при первом запуске и содержит все данные о пользователях, достижениях, мероприятиях, бронированиях и челленджах.
